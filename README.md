# ![Quizzies Logo](public/images/logo.svg) Quizzies

## Interaktywna platforma do quizów

**Quizzies** to aplikacja webowa do tworzenia i rozwiązywania quizów, zbudowana w **Laravel** z użyciem **Breeze**.  
Użytkownicy mogą się rejestrować, logować, weryfikować e-mail, tworzyć quizy, dodawać pytania i odpowiedzi, oraz rozwiązywać quizy online.

---

## Funkcjonalności

- Rejestracja i logowanie użytkowników
- Weryfikacja e-mail po rejestracji
- Tworzenie quizów i pytań
- Dodawanie wielu odpowiedzi do pytań (w tym oznaczanie prawidłowych)
- Rozwiązywanie quizów i sprawdzanie poprawnych odpowiedzi
- Panel użytkownika do zarządzania quizami

---

## Technologie

- [Laravel](https://laravel.com/) (PHP framework)
- [Laravel Breeze](https://laravel.com/docs/10.x/starter-kits#breeze-and-blade) (prosty system logowania i frontend)
- Tailwind CSS (stylowanie)
- MySQL (baza danych)
